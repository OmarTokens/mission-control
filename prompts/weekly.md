# Weekly prompt (use as a scheduled task: Fridays after the close)

> Run the Mission Control weekly review from `prompts/weekly.md` in this project. Research only.

---

## Agent: each Friday

1. Rebuild the snapshot from the live tracker (same as the daily scan, step 3).
2. **Scoreboard.** Week and since-start % for the household vs the benchmark (History tab), adjusted for deposits the user told you about.
3. **Mix.** Each sleeve vs target and the drift band; how the gaps changed this week.
4. **Value sleeve.** Each name: price vs zone, gain %, and whether the reason it was cheap still looks temporary. Flag, never insist.
5. **Plug-ins.**
   - [Value Cruiser](https://github.com/OmarTokens/value-cruiser): if the user runs it, include its Friday logbook line and make sure the tracker's targets match its core.
   - [Twin Turbo](https://github.com/OmarTokens/twin-turbo-trader): if the user runs it, include its Pit Report line (week vs QQQ) and its current value as a satellite.
6. **Next week.** Earnings for held and value-sleeve names, Fed/CPI dates, any planned deposits.
7. Email it (only to the saved address) with the snapshot block on top. Log it in the Daily Log as scan "Weekly".

Guardrails: same as the daily scan.
